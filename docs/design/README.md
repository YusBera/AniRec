# Design records

These files preserve decisions and evidence from earlier UI and integration
work. They are not the project entry point. Start at `../START_HERE.md`.

| Document | Use it for |
| --- | --- |
| `RECOMMENDER_EVALUATION.md` | Current measured ranker evidence and limits |
| `REACT_PRESERVATION_AUDIT.md` | Evidence about preserving the React Discover experience |
| `LIBRARY_WORKSPACE_SPEC.md` | Approved Library-led composition reference |
| `WORKSPACE_FUNCTIONAL_EXTENSION.md` | Implemented workspace extension record |
| `WORKSPACE_IMPLEMENTATION.md` | Earlier implementation and verification record |
| `ICON_HANDOFF.md` | Icon geometry and asset-generation rules |
| `POST_MODEL_FEATURES.md` | Older feature ordering; verify against current task/history before using |
| `BUNDLE_HANDOFF.md` | Earlier franchise-bundle analysis and unresolved relation-data limits |
| `LATEST_AGENT_HANDOFF.md` | Historical branch-transfer evidence despite its filename |
| `MIGRATION_HANDOFF.md` | Historical desktop-to-web migration record |
| `FRONTEND_HANDOFF.md` | Historical PySide visual-system record |
| `BACKEND_HANDOFF.md` | Historical frontend-raised backend issues |

Do not add another session handoff. Put active scope in `../CURRENT_TASK.md`,
completed evidence in `../TASK_HISTORY.md`, and durable rationale in
`../DECISIONS.md`.
