# Candidate structures

Established world: AniRec. Mode: Operate. Visual concepts requested before code.

Ordered by fit, before the surface seed:

1. Evidence board — pinned summary and ranked evidence modules; Profile leads.
2. Split workbench — left records, right persistent inspector; selection keeps context.
3. Reading ledger — a continuous, spacious dossier with clear section navigation.
4. Comparison matrix — shared columns and aligned differences; Compare leads.
5. Library-led workspace — artwork and a compact decision queue anchor every tab.
6. Activity timeline — recent decisions and viewing history with supporting evidence.
7. Progressive stations — one primary question at a time, with expandable depth.

Every option preserves the indexed navigation, palette, fonts, honest sample stamps,
actual scores and titles, and explicit unavailable states. Timeline is viable only
for recorded events, never synthesized behavior. Library concepts distinguish the
current recommendation collection and saved picks from an unimplemented full MAL list.
